This is a human-readable summary of the r26d local changes used to build Linux AArch64 host tools.
It is not a directly applicable patch file. Apply the changes carefully to the matching Android r26d toolchain source tree.

Base:
  NDK: r26d / 26.3.11579264
  Android clang: 17.0.2 based on r487747e
  toolchain/llvm_android: 0f058ab00ec6c9b8b39956c1393bcc405a5498d3
  toolchain/llvm-project: c4c5e79dd4b4c78eee7cffd9b0d7394b5bedcf12

project external/toolchain-utils/
  Checked out the revision compatible with the r26d Android LLVM build scripts.
  source_manager.py was adjusted to pass --filesdir_path to patch_manager when needed.

project toolchain/llvm_android/

py3_utils.py
  Use the host Python interpreter instead of Android's x86 prebuilt Python.

paths.py
  Point CMake, Make, Ninja, Python, and bootstrap LLVM/Clang references to Linux AArch64 host tools.
  Important intent:
    CMAKE_BIN_PATH -> /usr/bin/cmake
    MAKE_BIN_PATH  -> /usr/bin/make
    NINJA_BIN_PATH -> /usr/bin/ninja
    Python         -> /usr/bin/python3

configs.py
  Change Linux host configuration from x86_64 to AArch64:
    llvm_triple -> aarch64-unknown-linux-gnu
    gcc_triple  -> aarch64-linux-gnu or host equivalent
    sysroot     -> none / host-rooted setup suitable for the local AArch64 host

builders.py
  Stage1Builder must include AArch64 as a target backend.
  In the tested build, stage1 CMakeCache contained:
    LLVM_DEFAULT_TARGET_TRIPLE:STRING=aarch64-unknown-linux-gnu
    LLVM_TARGETS_TO_BUILD:STRING=AArch64;X86
    LLVM_ENABLE_RUNTIMES:STRING=

base_builders.py
  For stage1, avoid enabling LLVM runtimes and builtins target lists.
  Set LLVM_DEFAULT_TARGET_TRIPLE for Linux to the current config triple.
  Keep stage1 focused on producing a usable AArch64 host compiler.

do_build.py
  Use:
    stage1.build_android_targets = False
  Guard stage1 header-link generation when runtimes are skipped.
  Avoid building unnecessary Windows/LLDB paths by invoking build.py with:
    --no-build windows,lldb
  Use:
    --skip-tests --no-musl --skip-runtimes

Build command:
  cd ${SOURCE_ROOT}
  export PYTHONPATH="$PWD/external/toolchain-utils${PYTHONPATH:+:$PYTHONPATH}"
  python3 toolchain/llvm_android/build.py \
    --incremental \
    --no-build windows,lldb \
    --skip-tests \
    --no-musl \
    --skip-runtimes

Observed stage2 status:
  The full stage2 build failed late in builtins-i386-unknown-linux-gnu because the AArch64 host lacked i386 glibc headers/sysroot.
  The required out/stage2/bin host tools had already been produced and were verified as Linux AArch64 executables.

NDK overlay:
  Copy ${SOURCE_ROOT}/out/stage2/bin/. to:
    ${NDK_R26D}/toolchains/llvm/prebuilt/linux-x86_64/bin/

  Copy ${SOURCE_ROOT}/out/stage2/lib/libxml2.so.16 to:
    ${NDK_R26D}/toolchains/llvm/prebuilt/linux-x86_64/lib/libxml2.so.16

SDK/Gradle notes:
  Android Gradle Plugin may invoke SDK CMake/Ninja and Maven aapt2.
  Replace or wrap SDK cmake/ninja with AArch64 versions.
  Override Maven aapt2 with:
    -Dorg.gradle.project.android.aapt2FromMavenOverride=${ANDROID_SDK_ROOT}/build-tools/34.0.0/aapt2
